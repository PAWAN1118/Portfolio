# Pawan Kumar Nimmakayala - Portfolio

Personal portfolio for Pawan Kumar Nimmakayala, AI/ML Engineer and Full-Stack Developer.

## Contents

- Professional experience and measurable engineering outcomes
- Selected projects with live product and repository links
- Technical skills, education, certifications, and contact information
- Downloadable resume

## Run locally

Open `index.html` in a browser, or run `run-portfolio.bat` on Windows to start the local preview server.

## Deploy with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site will be published at `https://pawan1118.github.io/Portfolio/` after GitHub Pages finishes building.
